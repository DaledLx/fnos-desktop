# 飞牛桌面

一个 Windows 桌面客户端，用独立会话打开多个飞牛 fnOS 网页账号。每个账号可使用同一台 NAS 地址，也可使用不同 NAS。首次添加后在飞牛原网页中登录，之后点击左侧账号即可切换。

## 使用

1. 安装 Node.js 20 或更新版本并运行 `npm install`。
2. 开发运行：`npm start`。
3. 生成 Windows 安装包及免安装版：`npm run dist`。输出位于 `dist/`。
4. 打开程序，点击左侧 `+`，输入显示名称和浏览器里访问飞牛的地址（例如 `http://192.168.1.10:5666`），保存后在飞牛页面登录。第二个账号重复添加即可。

账号地址和名称保存在当前 Windows 用户的应用数据目录。各账号使用不同的 Electron 持久化分区；临时会话 Cookie 使用系统加密 API 保存。程序不保存明文密码，也不能绕过飞牛服务端的登录有效期、强制退出或二次验证。删除账号会清除其 Cookie、站点存储和本地会话快照。只应在可信的 NAS 地址上登录；HTTP 局域网连接本身不加密，能用 HTTPS 时优先使用 HTTPS。

这是非官方客户端。网页登录、上传、下载等功能由飞牛网页提供；某些需要额外浏览器权限或跨站弹窗的功能可能仍需在系统浏览器使用。
